# Public Notes Style Guide

This site is a UX learning and reference base. Notes should be consistent, skimmable, and example-driven.

---

## Required frontmatter (public notes)

---
type: concept
domain: ux-design
level: beginner
status: stable
summary: One sentence describing what this page teaches.
---

- type: concept | method | principle | checklist | template
- level: beginner | intermediate | advanced
- status: stable
- summary: required

To hide a note:

---
draft: true
---

---

## Standard structure

## What It Is
## Why It Matters in UX
## When to Use It
## Example
## Common Mistakes
## Related Concepts

Rules:
- Short paragraphs
- Prefer bullets
- Define jargon on first use
- Every concept page needs an example
- Link related topics with [[wikilinks]]
